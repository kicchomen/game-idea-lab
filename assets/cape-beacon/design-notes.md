# 岬の灯台守 · 2026-11-20
プレイヤーは船長ではなく灯台守。船の「合図待ち」と残り秒数を見て、灯り一本の行き先を選ぶ。
最初の数秒で光に反応して船が曲がる。先を見て照射順を選ぶ遊びを試し、将来は複数灯台の引き継ぎ・濃霧での視界変化に展開できる。10分・1時間継続や面白さは未検証。
Sensor Shiftの編集→再生と違い連続進行。タグボート・風読みヨットと違い船は自走。分岐番と違い同じ地点の荷物を仕分けず、別々に接近する3隻に一つの灯りを割く。絵は概念イラスト。
## PDCA
Plan: 3隻を対応する浮標の連続照射で誘導。固定案を実装。
Check: 独立確認で、初版の固定時間窓は2秒ごとに順番切り替えだけでも3隻通過。点滅の説明と表示、岸側の破線と船の経路にも差があった。
Act: 到着順3通りを連続成功で切り替え、個別の残り秒数、持続時間の表示、船の印、経路線を修正。失敗は同じ到着順でやり直せる。
Recheck: 6エンジン検査。締切を読んで照らす方策で全3通過。6順×1–45 tick周期×全位相を試し、同一の固定周期で全3成功する組み合わせなし。個別ステージの暗記や人の初見・長期の手応えは未検証。
