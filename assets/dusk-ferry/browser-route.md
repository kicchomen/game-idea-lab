# 夕ぐれフェリー：実ブラウザー検査担当向け

## 操作と画面
`games/dusk-ferry/index.html`。新規開始時すでに運航中だが実時間は進まない。乗客ボタンで選択（押下状態）、目的港の「出港」で確定。乗船中の人は自動降船。Tab/Enter/Spaceはネイティブボタン操作。Enter/Spaceのkeydown.repeat抑止。チェックや出港でDOM再生成するが同じIDのボタンが残ればフォーカスを復旧。定員で新規乗客ボタン無効、給油ボタンは灯台港・燃料8未満のみ。

## 自然失敗・再挑戦
「1刻待つ」を14回→目標未達0人、操作無効、やり直す→時刻0/燃料8/未選択。途中再挑戦は確認ダイアログ、終了後はそのままリセット。乗客Aボタンを2回で選択/解除し、時刻0のまま。A/B同時選択可能、出港で2人乗る。灯台→丘直行は2刻・燃料2。

## 幅・確認依頼
320/360/390 CSS px、記事内iframeはさらに狭い場合あり。レスポンシブDOM（最小固定幅なし）、ボタン48px以上。表は12pxで3港名を折返し。実際の横はみ出し、チェックボタン操作、選択解除、複数回出港、終端結果、リトライ、全時刻表を検査。物理スマホ/初見人ではないことを明記。
