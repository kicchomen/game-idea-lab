# 夜の森の音さがし
UIは生成した実ゲーム画面 `ui-design-reference.png` を開いて確認した後に実装した。企画カバーとは別物。操作できるCanvasとHTMLを作り、生成画像をゲーム背景として貼り付けてはいない。

## 遊び
指向性マイクを左右に回す。隠された鳴き声の方向に近づくほど琥珀の粒が増える。マイクを向けたまま中央の「記録」を押す。観測は20秒ずつ2回。各100点で方角のずれに応じて減点、時間切れは0点。各70点以上かつ合計154点以上で成功。「もう一度」で異なる方角の組合せへ進む。全4組。PCは← →、Enter。ボタンはタップで3°ずつ、押し続けると連続回転。音を鳴らさなくても遊べる。不明な方向を探索する遊びで、目印そのものを画面に先に出さない。

## 確認した点
- 生成UIと同じ濃紺、ミントの方位目盛・分割リング・扇形、マイク、青い木立、観測と秒数のピル、琥珀の12粒と中央ボタン。
- 初回は操作前なので「はじめる」、実際の観測時はリファレンスと同じ「記録」。結果はレーダーにメッセージを重ねる。音声なしでも成功でき、色以外に点灯粒の数と見え方、読み上げ用の数値を用いる。
- 固定高さの320/360/390×445 埋め込みでは画面全体に入れるためレーダー正円比を維持したまま少し縮める。狭くして操作を切り落とさない。
- ゲームの正確さ・時計・入力は Node の8件および本番JSを駆動するモックDOM＋実Canvasで検査。198点成功、 deliberate loss（意図的な失敗）、再試行、時計、停止/再開、時間切れ、長押し、指キャンセル、フォーカス喪失を確認。照合見本は `ui-reference-comparison.jpg`（右はCanvas実レンダリング＋CSS寸法再構成、実ブラウザではない）。
- `qa.html` にはPC 900×650、スマホ想定320/360/390×445の実ブラウザ検査と状態別キャプチャ補助。成功・失敗・再挑戦、ドキュメントのはみ出し、44px以上の操作、レーダー高さを確認する。ブラウザや物理実機の検査は実施結果が届くまでは未確認。公開未実施。
