# 氷上の寄せ石 — 2026-10-26

## 体験から選ぶ
村の氷遊びに参加した投げ手になる。目標にそっと寄せるだけでなく、邪魔な置き石を押し動かし、前の一投がつくった配置に次の石を重ねる。石を放したあとは手を離して見届ける。主動詞は「寄せる・押す・残す」。

最初の5–10秒は、弱すぎれば手前で止まり、ぶつければ両方が動く、手触りと結果の対応。10分の展開として、先に相手を押し出すか、自分の近い石を守るか、壁を使うかを考える構想。1時間の広がりは対人の交互投石、配置の持ち越し、異なる氷面の読み合いなど。後二者はこの固定3配置・3投の試作に未実装であり、長時間の面白さを保証しない。

## 既出構造との差
- ちいさなタグボート: 連続操船と追従隊列の角回り。今回: 一投を確定したあとは操作できず、衝突後に残った石を次投の条件とする。
- Sensor Shift: 一要素を編集して同じ初期盤面から再生。今回: 各投の結果が消えず、3投の配置変化が累積。再生のやり直しではない。
- 足あとエコー: 既知の遅延自分と離散手順。今回: 慣性・摩擦・接触の連続位置。
- 水車町の一週間: 選択カードと生産資源の蓄積。今回: 在庫ではなく空間の近さと押し合い。
- 引越しトラック: 矩形配置と将来の空白。今回: 置いた瞬間の静的パッキングでなく、投げた石と既存石の物理相互作用。
- 皿まわし/綱渡り/シャッターチャンス: 時間中の維持・反射・タイミング。今回: 投げる前の判断と、操作しない物理的推移。
- 牧羊犬: 継続的な間接誘導。今回: 有限回の離散的な射出で、結果が盤面に残る。
- 取り引き/忘れ物窓口: 言語/論理と返答。今回: 非言語の距離・角度・力。

テーマだけ変更した案ではなく、入力時間構造と勝利条件を変更した。とはいえ既知の「カーリング的な寄せ石」の一般的仕組みを小さく試すもので、ジャンル自体の発明を主張しない。実際のカーリングルール・摩擦・カーブを忠実に再現したものでもない。

## PDCA
1. Plan: 3投の位置が累積し、押す/寄せるの違いを観察できる核。
2. Do: 最初は全配置で中心(180,120)、半径65。摩擦と衝突を実装。
3. Check: 同じ0°/65を3回投げるだけで全3場面に勝てた。配置を変えても投げ手の判断が変わらなかった。
4. Act: 2・3場面の目標を左右に移し、輪を半径50へ。正面だけの同一ルートは2・3で敗北。初期0°/50も全配置で敗北する。
5. Independent review: 僅差を0.5未満なら引分けとする内部処理が説明と不一致→単純な厳密距離比較に修正。負け文『届かず』は輪内だが遠い場合に不正確→『青の勝ちにならず』に修正。aria-live文をフレーム毎に置換→文章変更時だけ更新。

## 手応えと未検証
強さ65の一定設定は、各場面で向きを合わせれば3回同じ一投でも勝てる。この既知ルートを覚えれば簡単になり、今回の3配置だけで深い戦略や長時間性が実証されたとは言えない。強い押し出しや壁反射にも別の成功経路があるが、人の初見テスト・実機スマートフォン・他ブラウザー・スクリーンリーダーの操作検証は未実施。難易度の基礎検証は自動エンジンと通常ブラウザー操作に分けて記録する。

## 実ブラウザー観察からの修正（01:36 UTC）
