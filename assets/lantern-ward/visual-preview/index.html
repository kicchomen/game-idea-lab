夜森の灯り番

灯の実 75結界 5/5波 0/5
台座 1 · 空き

灯りを置いて、最初の波を迎えよう。

灯りで、森の道を守る。

台座を選び、陽灯か月灯を置きます。陽灯は先頭の影を攻撃。月灯は範囲内すべての影を遅くします。影を払うと灯の実が3、波を越えると18増えます。

5波を守れば成功。5体が出口へ抜けると失敗。波の途中も設置・強化できます。灯りは移動・撤去できません。

数字1〜6: 台座 / S: 陽灯 / M: 月灯 / U: 強化 / Enter: 次の波 / P・Esc: 停止と再開 / R: やり直す。キーの長押しは連打になりません。

月灯の減速は重複しません。強化すると範囲と攻撃力が上がります。画面を離れると自動停止します。
