# からくり織り工房の企画と改善

プレイヤーは途中の布を預かった織り手。指定色が少ない見本を眺めて、その自由を糸が浮かない方へ使う。最初の2段は選択肢が1つずつで、押した柄が布の一段になる手触りを伝える。3段目から、同じ見本を満たす選択肢が複数になり、後の段まで考える意味が出る。

| 最近の案 | 遊びの構造 | 今回の違い |
| --- | --- | --- |
| 「渓流の糸つかい」 | 張りの変化を読みながら巻く・緩める連続操作 | 時間制限なし。選んだ織り目はその場で布に残り、後の制約になる |
| 「路地のかくれんぼ」 | 古い音と移動を照合して相手に先回りする | 見本と4つの操作を最初から表示。考える対象は自分が積んだ色 |
| 「森の切り札便」 | 相手の手札を読み、札勝負の勝ち数を合わせる | 相手や手札消費なし。同じ織り方をいつでも選べるが、使い方で布の強さが変わる |
| 「ろくろの小さな工房」 | 複数箇所へ波及する圧力で目標形状へ寄せる | 隣への波及や繰り返し修正より、上から進む不可逆の履歴を扱う |

## 試作した範囲

6列×8段の見本1枚。青緑と生成りの2色、4種の織り方、指定のないマス、連続色3段で注意表示。指定色不一致か、同じ列で同じ色が4段連続したときは失敗。8段成功で完成。固定の見本で再挑戦できる。糸の浮きの閾値はゲームのルール。

10分程度の展開として、異なる見本に対してより先の段を読む余地がある。1時間規模の構想では、注文によって使える織り方が変わる、完成した模様を別の人へ見本として渡す、布を横から継ぐなど、選択と完成品を結びつける。今回の試作で確認したのは固定見本の成立と操作で、これらの拡張も長期の面白さも未検証。

## 企画 → 試作 → 検証 → 改善

1. 最初は全てのマスを指定する案を検討したが、色合わせだけで織り方が決まりやすい。各段に指定色を2マスだけ置き、残り4マスを自由にした。試作前に行ごとの候補と、連続色の制約を両方調べて見本を選んだ。
2. ImageGenでUIを生成し、実装前に目視。題字帯、生成り地、横並びの盤、織り布の木枠、現在段の琥珀色の枠、下部2列2段の操作、青緑・蜂蜜色・くすんだ赤を採用。UI案の見本は全部指定だったため、実装では自由マスを「・」に置き換えた。
3. 6作者テスト、全65,536系列の照合と貪欲手の行き止まり検査を実施。独立レビューでは見本だけを守る16系列中2系列が完走することを別実装で確認。一手ずつ直近の安全だけで選ぶ方法では最終段で詰まる。
4. 独立レビューを受けて、間違ったマスの模様を残し、枠と「×」を重ねるよう変更。警告と本文にも次の見本を見る操作を明記。変更後に見本と布の元の色を残すブラウザーテストを追加し、再検証した。

## 画像
