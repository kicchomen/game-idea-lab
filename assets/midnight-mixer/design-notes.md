# 深夜ラジオのミキサー｜企画と試作
2026年11月26日。閉店間際ではなく、今その瞬間に番組を聞いている人へ、裏方として一つの放送を渡す。最初の5秒で進行表を読み、音楽からトークへつなぐ。強制的に正解へ切り替わらず、選んだ音が実際にクロスフェードする。先走ると前の音を削り、待ちすぎると次の音が遅れる。音はミュート初期値で、音楽、トーク、ジングルはすべて外部素材のない合成音。収録音声ではない。

## 類似案との差
- Echo Drum: 手本の発音位置を再現する音楽ゲーム。今回は同じ音を押し直す必要がなく、選んだチャンネルは持続し、前後区間の文脈で成否が変わる。
- Followspot: 動く人を照明で追う空間照準、熱・光漏れの管理。今回は操作位置でなく、三つの音の混合と引き継ぎ。
- Rail Dispatch: 列車の進路・駅の競合。こちらは進路や資源でなく、一つの番組を続ける作業。Sensor Shiftのような調整後の自動再生ではない。
- ほかに連続操作の版画工房と、複数階を扱う配車係も比較。前者は近作の職人工房と重なり、後者は進路選択が中心になる。この試作は音の継ぎ目を手で担当できる案を選んだ。

10分後の広がりは、予定から外れたトークの長さを聞きながら次を調整すること。1時間遊ぶなら、CMまたぎや生電話による進行の組み直し、時間帯別の番組構成。今回実装するのは28秒の固定進行表一つだけ。実地のミキシング教育や長期の面白さを証明するものではない。

## PDCA
1. 最初に画像生成で、実際のプレイ画面のPCと360幅を横に並べた。ブログ表紙は別に生成。実装は生成の後。
2. 金枠、夜のスタジオ、3分割の進行表示、切り替え先、6区間タイムライン、琥珀・水色・紫の3チャンネル、対応の3ボタンをHTML/CSSで再現。ヘッダーの夜景は参照の絵部分から切り出し、文字とバッジはHTML。
3. 独立レビューで実音と指示の混同、状態バッジ、キュー読み上げ、背景に残る生成画像のバッジ断片を指摘。指示名を「切替先」へ、待機/放送/休止/終了バッジとARIA通知を追加し、元画像に焼き込まれたバッジはトリミングから除外。停止系と音ボタンは下に集約し、合図を読んで操作する領域を優先。
4. テスト：純エンジン7件、独立DOMモックは30/60/144Hzでキーバインドとタップ相当のクリックを比較。0.5秒程度の遅れまでは回復可能、0.75秒で一部が失敗。合否両方を作れるが、初見の人による難易度・長期プレイ・実機は未検証。シナリオは5/6で合格。実際に流れる音の比率が成立した時間を判定に使う。

余白と高さを抑えるため、スマホでは波形を小さくし、PC/スマホ両方で全チャンネルを同じ順序に配置した。
