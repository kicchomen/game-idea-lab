# 霧の島の地図師 — 2026-10-28

## 選んだ体験
地図のない島の調査員として、まだ歩いていない道を地図に残し、自分で決めた道で野営地へ帰る。主動詞は **見渡す・歩く・道を選ぶ・帰還する**。発見した名所は見えただけでは成果にならず、実際に足を運ぶ。見渡して先に行き止まりや森を知るために、歩くための昼を使うかどうかが核。

これは一つの設定を変更して再生するパズルではない。毎手の情報が地図に残り、次に行く場所をその場で選ぶ。隠れた即死マスや判定の乱数はなく、隣接地形は歩く前に見える。未知への一歩で突然通行不能になって昼を失うことはない。

### 既出作品との構造比較
- **深海サルベージ**：全経路・価値が既知で、荷物の重さが帰りのコストを変える。本作は荷物・銀行・複数潜水なし。地形情報そのものが未確定で、先読みの範囲と徒歩で開く範囲を使い分ける。帰還資源という共通点はあり、完全に無関係な構造とは主張しない。
- **砂の下の博物館**：隠れた骨の連結を読み、道具のコストと破損を選ぶ。本作は図形をすべて掘り出すのでなく、移動主体の位置と帰還経路がある。遠くを見る行動により通る道を変える。
- **忘れ物窓口の探偵**：証言の関係から一対一対応を推理。本作は人物への割当や一意解はなく、複数の調査経路と名所の組み合わせを許す。
- **貝がらの競り市**：競争相手と同時に札を出し、相手の財布と所有が次の品へ影響。本作には相手・価格・競りがない。
- **氷上の寄せ石**：投げた後の物理衝突を評価。本作は実時間物理・照準・実行待ちがなく、観測範囲と経路の探索。
- **水車町の一週間**：設備の累積生産と在庫。本作は生産なし。有限の昼を使い、持ち帰る地図の情報を増やす。

## 最初の数秒・10分・1時間の企画
- 5〜10秒：野営地から一歩進むと霧が晴れ、道が紙の地図へ残る。見渡すと遠くの名所が見えるが、昼が2減る。
- 10分の仮説：3島で見渡す場所を選び、遠回りの森と平地の近道を比較する。同じ島で別の2名所を巡る、全3名所や残りの昼を考える。これらが人にとって満足な深さになるかは未検証。
- 1時間以上の構想（未実装）：複数人で地図を持ち寄る遠征、帰還後の地図を次の旅へ引き継ぐ、気象で視界だけが変わる日、調査目的ごとに名所の意味が変わる依頼。単に6×6を増やすだけではなく、情報を共有・持ち越す価値へ広げる。

## 今回の実装範囲・正確なルール
- 固定3島、各6×6。白波の島は昼22、杉影・双岬は昼24。名所は各3つ、2つ以上を訪ねて野営地で「調査を終える」と成功。
- キャンプは左下（6行1列）。初期状態は現在地と上下左右だけ判明。移動後もその場所の上下左右を開示。
- 見渡すは昼2。現在地からマンハッタン距離3以内の地形を開示。見えた名所は訪問扱いにはならない。新しい情報がない見渡しは無効、昼を使わない。
- 平地・名所・キャンプに入る移動は昼1、森に入る移動は昼2。岩・範囲外へは移動不可。足りない昼では移動不可、無効な操作で消費しない。
- 名所の記録は初回訪問時のみ。何度訪ねても増えない。
- 帰還コストは判明済みの通行可能地形上で計算した、現在地からキャンプまでの最短消費。未発見の近道を含めず、未来の追加行動も含めない。残りの昼が下回ると警告するが、自動操作やリセットはしない。
- **昼がちょうど0でキャンプへ帰還し、名所が2つ以上なら成功を優先。** キャンプ外で昼0、または昼0帰還で名所不足なら失敗。昼が残っていても、キャンプで名所不足のまま終了を選べば失敗。
- 成功／失敗から同じ島をやり直せる。別の島ボタンと島選択あり。進行中のやり直し・島変更は確認を挟む。キャンセルは状態を保持。
- 固定の地図は再挑戦でも同じ。新しいランダム島・対人・キャンペーン・保存・通信・音声・アカウント・広告分析は実装しない。

## 実装境界
既存READMEの依存なし静的配信を継承。engine.js は不変状態遷移、ブラウザーとNodeテストが同じ実装を使う。app.js はDOM描画と入力。6×6地図は表示で、操作は別の44px以上のネイティブ方向ボタン。256px入れ子でセルが44px未満でも、セル自体を小さい操作標的にはしない。Tab/Enter/Space、矢印/WASD、Vが使える。キー長押し、180ms未満の連続確定、ダブルクリックの追加clickを抑える。

## ブラウザー再現用の経路
各操作は少なくとも200ms間隔。最後に「野営地で調査を終える」。開始時に見渡すを1回挟んでも成功。
- 白波：北×5 → 東×2 → 南×3 → 西 → 南×2 → 西。
- 杉影：北×3 → 東×2 → 南 → 東 → 南×2 → 西×3。
- 双岬：北×5 → 東×2 → 南 → 東×2 → 南×4 → 西×4。
- 通常失敗：白波で北／南を往復し昼を消費、名所不足で日暮れ。または初期キャンプで調査を終える。
- 再操作：岩へ進む／端へ進む／同じ地点で2回見渡す（2回目はdisabled）で消費が増えない。
