# 星庭の囲い番 — 2026-11-13

## Role and core
庭師として、安全な縁から草地へ線を引き、安全な場所に帰る。閉じた線と、虫がいない領域が花壇になる。自分の移動の軌跡が永続的な安全域へ変わる陣取り。

## Comparison
小包の分岐番は流れてくる物を共有スイッチで分類するリアルタイム判断。こちらは本人の連続した軌跡で地形を変えるターン制。霧の島の地図師は未知を明らかにして帰還する探索で、領域獲得ではない。庭先の羽根ラリーは反射/返球角度、影絵劇場は輪郭合わせ。本案は編集→再生でもない。

## Scope
実装は固定9×9盤面、外周32安全マス、内部49マス、36マス確保、80歩、虫1匹、♥3、4方向入力、結果、再挑戦、ルール。虫は現在方向に1歩進み、安全域があれば時計回りに向きを変える。虫が残る側は草地、虫がいない領域を花壇とする。完成線も花壇になる。虫の位置と現在の向きは常時表示。壁/自己交差は無料無効入力。直前の線へ戻る場合は線を消しながら戻り、1手と虫移動が発生する。無操作時は何も進まない。

## Depth vs experiment
5〜10秒: 初めて線が面に変わる手触り。10分: 虫の進路と線の長さ、すでにできた花壇を足場にした切り取り順を考える構想。1時間: 複数の虫、動く水路、花壇ごとの注文、選択式の道具を将来検討する。ただし本試作にはこれらを実装していない。固定盤面は最短経路を覚えると容易で、長期の奥行きや人の面白さは未検証。

## PDCA
Plan: 軌跡が地形になるコアを、小盤面・入力時だけ進む時間で試す。
Do: 最初は24/49マス、虫は右向きだった。
Check: 実エンジン探索で下へ8回だけで28マス確保し即クリア。さらに自己交差禁止だけでは自作の線に囲まれた場所で詰む場合があった。
Act: 目標36、虫は上向きにし直進の初手には衝突が生じるよう変更。1歩ずつの引き返しで線を消せるようにした。敵も動くので無償のUndoとは違う。
Recheck: 左1・下3・右3・下5の12手で36マス/♥3成功、初手下2で被弾、外周往復80歩で時間切れ。11 Node tests成功。これらは実ブラウザ操作の代わりではない。

## Design reference
親担当が生成した UI 案を実見。紺の夜、クリーム色の情報欄、青緑の花壇、金色の線を採用。生成画像の盤面は状態と不一致があるため、実装状態の証拠には使わない。320px可読性を優先し装飾を簡略化。盤面はviewport高で縮むが、文字12px以上、ボタン44pxを保つ。低すぎる画面での収まりはブラウザ検証が必要。
