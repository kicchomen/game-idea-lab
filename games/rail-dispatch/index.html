小さな駅の発車係

待たせる？ 今、出す？
小さな交差点で、12便を定刻に。

到着 0 / 12勤務 0.0秒
交差点：空き

行先を選び、交差点が空いたら発車。

最初の勤務へ

行先を選ぶ → 発車。交差点が空くまで3秒。到着まで5秒。各便の残り時間を見て順番を決めよう。

① 行先の分岐を選ぶ キー 1 / 2 / 3

② 空きを確認して発車 キー A / S / D

遊び方・操作

列車に書かれた行先と分岐を合わせ、待機線の発車ボタンを押します。発車後の分岐変更は走行中の列車に影響しません。

共用区間は3秒間、1両だけ。使用中に次の列車を出す・行先を間違える・到着期限を過ぎると安全停止です。発車から到着までは5秒。残り5秒より前の発車を目指そう。

1・2・3：行先／A・S・D：発車／P・Esc：一時停止。画面を離れると停止します。再開はボタンから。全12便を届けると成功。やり直しは同じダイヤです。
