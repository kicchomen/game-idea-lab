星灯りの屋根わたり

跳んで、空中でひと伸び。街の灯りを届けよう。

星灯り 0 / 3残り90秒
空中ダッシュ：使える右へ → 灯台

星灯りを3つ集めて、右端の灯台へ。

操作・コツ

← → / A D で移動。Space / ↑ / W でジャンプ。X / Shift で空中ダッシュ。スマホは下のボタンを使います。移動は押し続け、ジャンプとダッシュは押した瞬間に1回発動。

ダッシュは空中で1回。着地すると回復します。広いすき間は「右＋ジャンプ → 空中でダッシュ」。低い足場からも戻れます。高い屋根は近道の候補です。

90秒以内に星灯り3つを集めて右端の灯台へ。落下か時間切れで失敗。P / Esc で停止。別画面へ移ると自動停止します。

固定1コースの操作試作です。音・課金・保存はありません。
