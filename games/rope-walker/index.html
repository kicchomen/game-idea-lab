GAME IDEA LAB / CORE EXPERIMENT 15

山あいの綱渡り

風を読み、傾きを戻して、一歩ずつ。

あと 60.0 m残り 55.0 秒
風：右へ →5.0 秒後に左風
左へ傾く傾き 0%右へ傾く

動き：静止

風の向こうへ

歩くのは自動。左右の重心移動で傾きを戻します。危ないときは「踏ん張る」を長押し。55秒以内に向こう岸へ。

左右は短く。押しすぎると逆側に傾きます。

← → / A D：重心
Space：踏ん張る
遊び方と試作の範囲

傾きが端（±100%）に達すると安全ロープが作動して終了。左右のボタンは進行方向ではなく、重心を動かします。離しても少し勢いが残ります。踏ん張る間は歩みが止まり、揺れが小さくなりますが、時間は進みます。風の予告を見て備えましょう。

PCは矢印 / A D と Space。P / Escで一時停止。スマホは左右と踏ん張るを長押し（同時押し可）。画面から離れると自動停止します。1本の綱・固定の風だけを試せる小さな試作です。旅のルート選び、装備、演目は構想段階です。

音・保存・アカウント不要。実機スマホと初見の人による検証は未実施。
